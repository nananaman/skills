# Writing Skills

文書、記事、実験や検証の報告、解説、設計資料や判断資料などを、読者と目的に合わせて設計、執筆、レビューするための skill です。
日本語の文章規範もこの skill に含めます。

## どの Skill を使うか

- 文書の読者、目的、構成を設計して書く → [`chouge-writing`](./chouge-writing/SKILL.md)
- 実験や検証の報告、解説、設計資料や判断資料を書く → [`chouge-writing`](./chouge-writing/SKILL.md)
- 草稿を内容、論証、文章、媒体の観点でレビューする → [`chouge-writing`](./chouge-writing/SKILL.md)

## 典型フロー

1. `chouge-writing` で読者、目的、媒体、範囲、根拠を定める。
2. 文書の型を選び、構成と論証を組み立てる。
3. 執筆後に内容、構造、表現、媒体をレビューし、必要なら renderer / viewer で成果物を確認する。

## Skill 一覧

- **[`chouge-writing`](./chouge-writing/SKILL.md)** — 文書の読者、目的、構成を設計し、根拠と不確実性を保って執筆とレビューを行う個人用 writing skill。日本語の文章規範と長文の構成も含む。
  - Use when: 文書、記事、実験や検証の報告、解説、設計資料や判断資料の作成、推敲、レビュー
  - Type: `model-invoked`
