# 出典と変更

このスキルと機能マップ例は cursor/plugins の pstack にある create-verification-skill を日本語に翻訳・適応したものです。

- 原本: https://github.com/cursor/plugins/tree/e1cc03121a0e71129a4fb730d7c5528a0a3e43c8/pstack/skills/create-verification-skill
- 取得日: 2026-11-17
- ライセンス: pstack/LICENSE の MIT License（下記を保持）
- 変更: 生成先を `.cursor/skills/` から `.agents/skills/` へ変更。本文と機能マップの見出しを日本語化。Cursor 固有の明示起動制限と未同梱の保守スキルへの固定案内を除去。検証と無関係な修正・外部副作用を依頼範囲へ広げない条件を明記。例の証拠取得タイミングを操作結果の直後に整理。
