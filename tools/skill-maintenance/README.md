# 旧maintenanceの保管用tools

renderer、証拠索引、許可された入力専用readerと、その資材を維持するための保管先です。
SKILL.mdは置かず、native pluginの配布・skill検出対象から外しています。
この移動は自動化設定や履歴の取得許可を変更しません。
既存の日次runnerは稼働中の旧導入版を使用し、切替時に別途停止・目的変更を承認します。

新しい学びの入口は明示呼出しのpstack reflectです。
その提案を本人管理の正本へ反映する場合は、今回許可された操作と評価・配布手順に従います。
readerは合成fixtureのunit検査以外では起動せず、拒否済み履歴の再取得に使いません。
